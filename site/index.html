How it works

Paste a link or drop a file. Each step after that runs on your machine except one: the editorial pass, which sends transcript text to Claude.

Ingest

Any yt-dlp link or a local file, validated with ffprobe. Rotation, variable frame rate and multiple audio tracks are handled.

on your Mac

Listen and look

Word-level Whisper transcription, speaker detection, energy, laughter, shot changes, motion and platform heatmaps.

on your Mac

Curate

A cheap Claude scan finds candidates, then a stronger Claude model picks and ranks clips. Boundaries snap to word and sentence edges.

Claude API · text only

Render

Speaker-aware 9:16 reframing, designer captions, filler cleanup and -14 LUFS audio, all in one H.264 encode.

What's built today

Six build phases are complete, covered by 236 backend tests plus web unit and Playwright suites.

Speaker-aware reframing

Single, two-shot, stacked, screen-plus-cam and blurred-fit layouts. The face stays in the crop in over 98.5% of frames.

Designer captions

Eight templates with word-by-word highlight, hook overlays and brand kits. Rendered by Remotion, with a libass fallback.

Text-based editing

Select words in the transcript to cut them. Drag to trim, restore fillers, and switch templates live. Fully keyboard-driven.

Character-edit mode

Name a character in an episode or film. Claude checks small shot thumbnails to find their scenes, then Clipforge cuts a graded montage.

Publish or package

Upload to YouTube with scheduling, or get a ready-to-post folder with copy for Shorts, Reels and TikTok.

Pro exports

OpenTimelineIO, FCPXML, FCP7 XML and CMX 3600 EDL, so you can finish a cut in your NLE of choice.

How Claude is used

The model does the editorial judgement: reading a transcript the way an editor would, finding the opening that hooks and the payoff that lands, and ranking candidates. Clipforge then snaps every cut to exact word boundaries, so the model never decides frame timing.

Curation runs in two stages. Claude Haiku does a cheap scan and a stronger Claude model makes the final picks. A live cost meter and a hard per-job cap (default $1) mean a long video can't run up a surprise bill.

The clip score is labelled a heuristic. It's not a virality prediction, and the UI says so.

What leaves your machine

  • Video fileNever. Decoding, reframing and encoding are all local.
  • AudioNever. Transcription runs locally with Whisper.
  • TranscriptText and light metadata go to the Claude API for curation.
  • ThumbnailsCharacter-edit mode only: small still frames, so Claude can tell who is on screen.

Where it stands

Clipforge is early: a working studio built by one developer, run locally. Here's what's next and what isn't proven yet.

Next up

  • Live-test YouTube upload with a real OAuth client, then pass Google's audit so public uploads stick
  • Better word-onset accuracy with a per-language CTC aligner
  • Verify active-speaker detection on real multi-speaker footage
  • Speech enhancement for poor audio
  • Validate character-edit mode end to end on full-length episodes

Known gaps

  • Speaker diarization needs you to accept the pyannote model terms on Hugging Face
  • YouTube upload has only been tested against a protocol-level mock
  • Instagram and TikTok have no upload API a local app can use, so posting there is manual via the ready-made package
  • macOS on Apple Silicon is the target. Other platforms are untested.

Try it

On a Mac, double-click install_and_run.command in the repo. It installs the dependencies, asks for your Anthropic API key and opens the app on localhost. The manual steps are on the right.

Only process videos you own or have permission to reuse.

# clone and set up
git clone https://github.com/kavan0910/ClipForge.github.io
cd ClipForge.github.io
make setup
cp .env.example .env   # add ANTHROPIC_API_KEY
make doctor
make start             # http://127.0.0.1:8765

# or from the CLI
clipforge run <url|path> --clips 8 --duration 30-60
